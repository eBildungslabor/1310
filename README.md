# Abschlussarbeiten und Prüfungskultur im Kontext von KI

Workshop-Material zu alternativen Prüfungsformaten an Hochschulen.

1. **[Präsentation](praesentation.html)** – Impuls zu KI, Lernen und Prüfen sowie die acht Achsen der Formatspinne. Blättern mit Pfeiltasten oder Klick, `F` für Vollbild.
2. **[Formatspinne](formatspinne.html)** – ein Prüfungsformat auf acht Achsen einstellen und als Netzdiagramm sehen.
3. **[Prompt-Generator](prompt.html)** – Fach und Thema eingeben, KI-Feld (mit / ohne / über KI) wählen, Spinne einstellen, Prompt kopieren. Die KI antwortet direkt mit einer Formatidee.
4. **[28 Formate](formate.html)** – kurz benannte Prüfungsformate mit KI, filterbar nach mit, ohne und über KI.
5. **[Zufallsidee](zufall.html)** – zieht groß eine zufällige Formatidee; Leertaste für die nächste.

Einstieg: [index.html](index.html), online unter https://ebildungslabor.github.io/1310/. Alle Seiten sind reines HTML ohne externe Abhängigkeiten und funktionieren mit GitHub Pages.

Die Formatspinne ist ein Reflexionstool des [Instituts für zeitgemäße Prüfungskultur](https://pruefungskultur.de/ressource/formatspinne/).
